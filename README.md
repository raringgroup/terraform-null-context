# terraform-null-context

Provides a consistent naming and tagging context (ID, tags, descriptors and DNS name) that is passed from module to module. It creates no resources.

Part of the [Raring Group](https://github.com/raringgroup) Terraform module library.

## Usage

```hcl
module "context" {
  source = "git::https://github.com/raringgroup/terraform-null-context.git?ref=v0.1.0"

  namespace   = "example"
  environment = "dev"
  stage       = "demo"
  name        = "app"

  tags = { Owner = "platform" }
}

module "child" {
  source = "git::https://github.com/raringgroup/<module-name>.git?ref=v<x.y.z>"

  context = module.context.self
}
```

Naming and tagging come from [`terraform-null-context`](https://github.com/raringgroup/terraform-null-context). Add `_context.tf` to the calling configuration and pass `context = module.context.self`.

`exports/_context.tf` is the file consumers copy into their own modules. It declares the standard context inputs and instantiates this module as `module.context` (accessible as the whole `context` object via the `context` variable). Do not edit copies of it; edit it only in `github.com/raringgroup/terraform-null-context`.

See [`examples/`](examples/) for complete, runnable configurations (`complete`, `dns_name`, `legacy`). The `legacy` example intentionally uses the upstream registry label module (`registry.terraform.io/cloudposse/label/null`) to verify backward compatibility of the `legacy` output.

### Behaviour notes

- Values passed as variables supersede values inherited from `context`, except `tags` and `attributes`, which are merged (attributes from variables are appended to those from context).
- The `id` is the normalized labels joined by `delimiter` in `label_order`. Default `label_order` is `["namespace", "environment", "stage", "name", "attributes"]`; `tenant`, `project` and `region` are only included if added to `label_order`. At least one label must be present.
- Labels are normalized by removing characters matching `regex_replace_chars` (default `/[^-a-zA-Z0-9]/`), then case-formatted by `label_value_case` (default `lower`).
- If `id_length_limit` is non-zero and `id_full` is longer, `id` is truncated and a 5 character hash is appended; `id_full` is never truncated. `0` means unlimited.
- `tags` include a `Name` tag equal to `id`, plus one tag per label in `labels_as_tags` (default: all labels, empty values omitted; `[]` suppresses all). Tag keys are cased by `label_key_case` (default `title`).
- `descriptors` renders each entry of `descriptor_formats` (`{ format = string, labels = list(string) }`) with `format()` over the normalized labels.
- `dns_name` is `dns_name_format` (default `${name}.${domain_name}`) with `${namespace}`, `${tenant}`, `${project}`, `${region}`, `${environment}`, `${stage}`, `${name}`, `${id}`, `${attributes}` and `${domain_name}` substituted.
- `enabled = false` makes the string outputs empty (`""`) so that consuming modules create nothing.
- `legacy` is the context without `project`, `region`, `domain_name` and `dns_name_format`, for modules that predate those attributes.

## Inputs

All inputs default to `null` (inherit from `context`) unless noted.

| Name | Description | Type | Default |
|------|-------------|------|---------|
| context | Single object for setting entire context at once. Individual variables override values in the object; `tags` and `attributes` are merged. | `any` | all values `null`, `enabled = true`, `label_order = []`, `labels_as_tags = ["unset"]` |
| enabled | Set to false to prevent the module from creating any resources | `bool` | `null` |
| namespace | ID element. Usually an abbreviation of your organization name | `string` | `null` |
| tenant | ID element (rarely used, not included by default). A customer identifier | `string` | `null` |
| project | ID element. Project name | `string` | `null` |
| region | ID element. Region | `string` | `null` |
| environment | ID element. Usually used for region, e.g. `uw2`, `us-west-2` | `string` | `null` |
| stage | ID element. Usually used to indicate role, e.g. `prod`, `staging`, `source`, `build`, `test`, `deploy`, `release` | `string` | `null` |
| name | ID element. Usually the component or solution name | `string` | `null` |
| delimiter | Delimiter between ID elements. Defaults to `-` (hyphen); set to `""` to use no delimiter | `string` | `null` |
| attributes | Additional attributes (e.g. `workers` or `cluster`) added to `id` in the specified order; merged with context attributes | `list(string)` | `[]` |
| labels_as_tags | Labels (ID elements) to include as tags in the `tags` output. Default is all labels; `[]` suppresses all | `set(string)` | `["default"]` |
| tags | Additional tags (e.g. `{'BusinessUnit': 'XYZ'}`); merged with context tags | `map(string)` | `{}` |
| additional_tag_map | Additional key-value pairs added to `tags_as_list_of_maps` | `map(string)` | `{}` |
| label_order | Order in which labels appear in `id`. Defaults to `["namespace", "environment", "stage", "name", "attributes"]` | `list(string)` | `null` |
| regex_replace_chars | Regex of characters to remove from ID elements. Default `/[^-a-zA-Z0-9]/` | `string` | `null` |
| id_length_limit | Limit `id` to this many characters (minimum 6). `0` means unlimited | `number` | `null` |
| label_key_case | Letter case of generated `tags` keys: `lower`, `title` or `upper`. Default `title` | `string` | `null` |
| label_value_case | Letter case of output label values: `lower`, `title`, `upper` or `none`. Default `lower` | `string` | `null` |
| descriptor_formats | Additional descriptors for the `descriptors` output: map of `{ format = string, labels = list(string) }` | `any` | `{}` |
| domain_name | Route53 Zone domain name | `string` | `null` |
| dns_name_format | Format string for the `dns_name` output. Default is `${name}.${domain_name}` | `string` | `null` |

## Outputs

| Name | Description |
|------|-------------|
| id | Disambiguated ID string restricted to `id_length_limit` characters in total |
| id_full | ID string not restricted in length |
| dns_name | A DNS name |
| enabled | True if the module is enabled, false otherwise |
| namespace | Normalized namespace |
| tenant | Normalized tenant |
| environment | Normalized environment |
| name | Normalized name |
| stage | Normalized stage |
| delimiter | Delimiter between ID elements |
| attributes | List of attributes |
| tags | Normalized tags map |
| additional_tag_map | The additional tag map |
| label_order | The label order used |
| regex_replace_chars | The regex used to normalize labels |
| id_length_limit | The `id_length_limit` actually used to create the ID, `0` meaning unlimited |
| tags_as_list_of_maps | List of one map per tag, each containing `key`, `value` and the contents of `additional_tag_map` |
| descriptors | Map of descriptors as configured by `descriptor_formats` |
| normalized_context | Normalized context of this module |
| legacy | Context compatible with legacy label modules; removes newer attributes |
| self | Merged but otherwise unmodified input to this module, for use as `context` input to other modules (null values are not replaced with defaults) |
| dns_name_format | DNS name format |
| domain_name | Domain name |
